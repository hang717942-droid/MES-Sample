# 스마트팩토리 MES 생산관리 시스템

Python tkinter와 SQLite로 구현한 Windows 데스크톱 MES 데모입니다. 외부 패키지 없이 Python 3으로 실행합니다.

## 실행

`run.bat`을 더블 클릭하거나 다음 명령으로 실행합니다.

```bat
run.bat
```

데이터는 프로그램 폴더의 `mes.db`에 저장됩니다. 기존 `production_records` 데이터와 제품 정보는 유지되며 새 MES 테이블이 초기화 시 추가됩니다.

## 기본 사용 순서

1. **기준정보**에서 제품을 확인하거나 추가합니다.
2. **생산계획**에서 계획일자, 제품, 수량, 납기일, 상태를 등록합니다.
3. **작업지시**에서 생산계획과 설비를 선택해 지시를 저장합니다. 번호는 `WO-YYYYMMDD-001` 형식으로 발급됩니다.
4. **생산실적**에서 작업지시를 선택하고 생산수량과 불량수량을 저장합니다. 양품수량과 달성률은 목록에 자동 계산됩니다.
5. **불량관리**에서 생산실적을 선택해 유형, 수량, 원인, 조치를 기록합니다.
6. **설비현황**에서 설비 상태를 변경하고 **대시보드**에서 당일 집계를 확인합니다.

각 입력 화면은 선택 행을 폼에 불러와 수정하거나 삭제할 수 있습니다. 삭제는 확인창을 표시합니다.
